# @territorios/mobile

Capacitor 8 shell around `apps/web`. The app always loads the **bundled** web build
(`apps/web/dist-mobile`, built with `vite build --mode capacitor`). There is no `server.url`:
pointing the WebView at Vercel would break offline use and reads as a "repackaged website" in
App Review (guideline 4.2).

```
apps/mobile/
├─ capacitor.config.ts      hardened config (see "Security baseline")
├─ src/native/platform.ts   native Platform (secure storage, geo, share, lifecycle)
├─ android/                 generated by `cap add android`, then hardened by hand. Commit it.
└─ ios/                     not generated yet: needs macOS (see "iOS")
```

The web app never imports `@capacitor/*`. `apps/web/src/platform/select.ts` dynamically imports
`src/native/platform.ts` only when `import.meta.env.MODE === 'capacitor'`, so the Vercel/PWA
bundle contains no native code. Check with:

```sh
pnpm build && grep -rlE "@capacitor|registerPlugin|SecureStorage" apps/web/dist/assets   # expect nothing
```

## Native adapters (`src/native/platform.ts`)

| Platform member                    | Implementation                                                                                                                                                                                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `secureStorage` (Supabase session) | `@aparajita/capacitor-secure-storage` 8.x: iOS Keychain `afterFirstUnlockThisDeviceOnly`, no iCloud sync; Android Keystore-wrapped AES-GCM. Uses the raw-string `getItem/setItem/removeItem` API (the `get/set` API JSON-parses values and would turn the session into an object). Supabase `signOut()` removes its key. |
| `storage` (query cache)            | `@capacitor/preferences` (survives WebView storage eviction)                                                                                                                                                                                                                                                             |
| `watchPosition`                    | `@capacitor/geolocation`: `checkPermissions` → `requestPermissions` → `watchPosition`; unsubscribe is safe before the watch id resolves                                                                                                                                                                                  |
| `watchHeading`                     | web `deviceorientation` fallback. **TODO (M0 spike):** native heading plugin if WKWebView compass is unreliable                                                                                                                                                                                                          |
| `share`                            | Blob → `Filesystem.writeFile` (Cache) → `Share.share({ files })` → temp file deleted                                                                                                                                                                                                                                     |
| `onResume`                         | `App.addListener('appStateChange')` when `isActive`                                                                                                                                                                                                                                                                      |

`@capacitor/haptics`, `network`, `splash-screen` and `status-bar` are installed for M1/M2 follow-ups
(back button, edge-to-edge status bar, offline banner) but not wired yet.

## Scripts

From the repo root:

```sh
pnpm mobile:sync                       # build apps/web --mode capacitor, then cap sync android
pnpm --filter @territorios/mobile open:android   # open in Android Studio
```

Run `cap sync` after every plugin install/removal and every `capacitor.config.ts` change. Never edit
`android/app/src/main/assets/public/`: it is overwritten on each sync.

## Android build on Windows

Requirements: Node 22+, pnpm 10, JDK 21 (Android Studio's bundled JBR works), Android SDK
(API 36, build-tools). Point Gradle at the SDK with `ANDROID_HOME`
(usually `%LOCALAPPDATA%\Android\Sdk`) or `android/local.properties` (`sdk.dir=...`, gitignored).

```sh
pnpm mobile:sync
cd apps/mobile/android
./gradlew assembleDebug          # debug APK: app/build/outputs/apk/debug/
./gradlew bundleRelease          # release AAB for Play (needs signing, below)
```

Release signing reads from environment variables or a gitignored `keystore.properties`; the upload
keystore lives **outside the repo** and is enrolled in Play App Signing. Wire the `signingConfigs`
block in `android/app/build.gradle` as part of M3.

## iOS (macOS only)

`npx cap add ios` needs macOS + Xcode 26, so `ios/` is not in the repo yet. Generate it once on a
Mac (or in CI) and commit it. Capacitor 8 uses Swift Package Manager by default (no CocoaPods).

GitHub Actions step (runner `macos-15` or newer), to add in `.github/workflows/ios.yml` (M3):

```yaml
- uses: pnpm/action-setup@v4
- uses: actions/setup-node@v4
  with: { node-version: 22, cache: pnpm }
- run: pnpm install --frozen-lockfile
- run: pnpm build:mobile
- name: Add iOS platform (first run only; afterwards ios/ is committed)
  working-directory: apps/mobile
  run: |
    [ -d ios ] || npx cap add ios
    /usr/libexec/PlistBuddy -c "Add :NSLocationWhenInUseUsageDescription string 'Territorios usa tu ubicación para mostrarte en el mapa de territorios.'" ios/App/App/Info.plist || \
    /usr/libexec/PlistBuddy -c "Set :NSLocationWhenInUseUsageDescription 'Territorios usa tu ubicación para mostrarte en el mapa de territorios.'" ios/App/App/Info.plist
    npx cap sync ios
- name: Archive
  run: xcodebuild -project apps/mobile/ios/App/App.xcodeproj -scheme App -configuration Release -destination 'generic/platform=iOS' -archivePath $RUNNER_TEMP/App.xcarchive archive
# then export + upload to TestFlight (xcrun altool / fastlane pilot) with the API key below
```

iOS checklist once `ios/` exists:

- `NSLocationWhenInUseUsageDescription` (Spanish, above). No "Always" location key.
- No `NSAllowsArbitraryLoads` in Info.plist; no `UIFileSharingEnabled`.
- Set the language to Spanish (`CFBundleDevelopmentRegion` = `es`) so system prompts match.

Watch macOS runner minutes: they are billed at a multiplier on private repos. Codemagic's free tier
is the fallback.

## Signing secrets

Store all of these as GitHub Actions secrets (never in the repo):

| Secret                                                | Used for                                               |
| ----------------------------------------------------- | ------------------------------------------------------ |
| `ANDROID_KEYSTORE_BASE64`                             | upload keystore (`.jks`), base64-encoded               |
| `ANDROID_KEYSTORE_PASSWORD`                           | keystore password                                      |
| `ANDROID_KEY_ALIAS`                                   | upload key alias                                       |
| `ANDROID_KEY_PASSWORD`                                | upload key password                                    |
| `PLAY_SERVICE_ACCOUNT_JSON`                           | (optional) automated upload to the Play internal track |
| `APPSTORE_API_KEY_ID`                                 | App Store Connect API key id                           |
| `APPSTORE_API_ISSUER_ID`                              | App Store Connect issuer id                            |
| `APPSTORE_API_PRIVATE_KEY`                            | `.p8` contents                                         |
| `IOS_DIST_CERT_P12_BASE64` / `IOS_DIST_CERT_PASSWORD` | distribution certificate (or use fastlane match)       |
| `IOS_PROVISIONING_PROFILE_BASE64`                     | App Store provisioning profile                         |

`VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` are **not** secrets (they ship in the
bundle by design); security rests on RLS. Never put a Supabase service-role or secret key in any
`VITE_*` variable.

## Distribution (from docs/research/02-mobile-stack.md)

- **Google Play**: personal developer accounts created after 2023-11-13 need a **closed test with
  ≥12 testers opted in for 14 consecutive days** before production access (organization accounts
  are exempt). Recruit 12+ publishers early; start on the internal track, then closed testing.
- **Apple Unlisted App Distribution**: the app passes normal App Review, then is reachable only via
  a direct link. Request it in App Store Connect after approval (not for beta builds). Suggested
  reason: "internal scheduling/maps tool for one congregation; not useful to the general public".
  It does **not** waive guideline 4.2: native geolocation, share, haptics, offline shell and push
  are what make the app more than a website.
- TestFlight internal testing first; Play internal track in parallel.

## App id

`ar.org.nortevilladiego.territorios` is a **placeholder**. Change `appId` in `capacitor.config.ts`
(and re-run `cap sync`; on Android also update `namespace`/`applicationId` in
`android/app/build.gradle`, the `package_name`/`custom_url_scheme` strings and the
`MainActivity` package path) before the first store upload. After that it is permanent: a new id
is a new store listing.

## Security baseline

Config (`capacitor.config.ts`): no `server.url` / `cleartext`, `allowNavigation: []` (every listed
host gets native-bridge access), `allowMixedContent: false`, `webContentsDebuggingEnabled: false`
on both platforms, `loggingBehavior: 'none'`. To inspect the WebView locally, flip
`webContentsDebuggingEnabled` to `true` in your working copy and never commit it.

Android (`android/app/src/main`):

- `allowBackup="false"` plus `fullBackupContent` / `dataExtractionRules` excluding everything
  (Android 12+ device-to-device transfer ignores `allowBackup` alone).
- `usesCleartextTraffic="false"` and `res/xml/network_security_config.xml`: HTTPS only, system CAs
  only, no user CAs, no `debug-overrides`.
- Foreground location only (`ACCESS_FINE/COARSE_LOCATION`, GPS feature not required); no
  background location.
- `FileProvider` exposes only the cache dir (used by share).

Audit with `npx @capgo/capgo-sec@latest scan --severity medium` from this folder (run after
`pnpm mobile:sync`; it also scans the copied web bundle).

Open items owned elsewhere: a Content-Security-Policy `<meta>` in `apps/web/index.html`
(capsec WEB004).
